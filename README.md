# Arquivo Maldito

Portfólio de uma página para profissional de audiovisual, produção e maquiagem, com estética de terror trash dos anos 80/90 (VHS, locadora, polaroids de continuidade).

HTML, CSS e JS puros, sem build. Para ver, abra o `index.html` no navegador.

Textos e imagens são provisórios: as fotos são degradês em CSS (classes `.g1` a `.g9`) e devem ser trocadas pelas fotos reais.
